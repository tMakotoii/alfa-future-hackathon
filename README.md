# Альфа Инсайт — персонализированная новостная аналитика для крупного бизнеса

Прототип модуля интернет-банка для групп компаний с выручкой > 15 млрд ₽ (кейс хакатона «Альфа-Будущее»).
Сервис не пересказывает новости: он отбирает события, значимые для конкретной группы и роли пользователя, и объясняет,
как они повлияют на бизнес. Каждое утверждение помечено как **Факт**, **Мнение Альфа-Банка** или **Вывод AI** и
связано с источником. Агентный цикл и его трасса видны в интерфейсе.

> Прототип для хакатона. Не является продуктом банка.

## Возможности

- Профиль группы из данных банка: отрасли по долям выручки, продукты банка (доля выручки участников с продуктом),
  ключевые поставщики и покупатели из платёжного графа, концентрация, регионы, позиция в отрасли (оценка по выборке).
- Сбор новостей из RSS (Банк России, Интерфакс, РБК, Финмаркет), ручной ввод текста или URL, офлайн-снапшот.
- Объяснимое ранжирование под группу и роль (CEO / финдиректор / казначей) без LLM.
- Агент: план → инструменты → синтез → самопроверка (код + LLM) → доработка; позиция банка из OCR-корпуса аналитики (RAG по FTS5).
- Интерфейс: главная с виджетом «Что важно сегодня» → лента → карточка по 6 вопросам → чат → «Как получен вывод».
- Метрики качества и стоимости, золотой набор, бюджет LLM с деградацией (fallback-модели → только кэш → карточки без AI).

Архитектура: [`docs/architecture.md`](docs/architecture.md). Дизайн-документ: [`docs/superpowers/specs/2026-10-24-alfa-insight-design.md`](docs/superpowers/specs/2026-10-24-alfa-insight-design.md).

## Требования

- Docker 24+ с Compose v2 — для запуска.
- Для разработки: Python 3.12 и [uv](https://docs.astral.sh/uv/), Node.js 20+.
- Данные: для демо ничего класть не нужно.
  - `data/demo/` (в репозитории, 2,8 МБ) — срез данных кейса: все компании (только нужные колонки, чтобы позиция в
    отрасли считалась по всей выборке) и платежи трёх демо-групп. Используется, если полных CSV нет.
    Пересборка: `python -m uv run python scripts/make_demo_slice.py`.
  - Полные данные кейса (все 341 группа с платежами) — положите `df_Uid_data_hack.csv` и `df_Uid_payment_hack.csv`
    в `data/Классы данных для решения задачи/`; тогда берутся они.
  - OCR-корпус аналитики уже в репозитории (`data/ocr/`), PDF не нужны.

## Запуск

```bash
cp .env.example .env        # впишите LLM_BASE_URL и LLM_API_KEY
docker compose up --build   # http://localhost:8000
```

При первом старте БД строится из CSV (около 1–2 минут на полных данных, ~15 с на демо-срезе), снапшот новостей грузится сразу, RSS обновляются в фоне каждые 30 минут.
Без ключа LLM приложение работает: лента строится по ручным новостям, карточки формируются без AI (`rule_only`).

### Переменные окружения

| Переменная | По умолчанию | Описание |
|---|---|---|
| `LLM_BASE_URL` | — | OpenAI-совместимый endpoint с разрешёнными моделями |
| `LLM_API_KEY` | — | ключ доступа |
| `DAILY_BUDGET_RUB` | `500` | дневной лимит; от 70 % — fallback-модели и стоп фонового агента, от 90 % — только кэш |
| `DEMO_MODE` | `1` | переключатель клиента/роли в шапке и выбор любой из 341 целевой группы |
| `SESSION_SECRET` | `change-me` | ключ подписи cookie сессии |
| `DB_PATH` | `/data/app.db` | файл SQLite (volume `appdata`) |
| `BACKGROUND` | `1` | `0` выключает фоновый сбор и предрасчёт |

### Конфигурация (без изменения кода)

| Файл | Что настраивается |
|---|---|
| `config/models.yaml` | модель и fallback на каждую задачу, цены ₽/1000 токенов, таймауты |
| `config/sectors.yaml` | чувствительность отраслей (ОКВЭД-2) к макрофакторам — новая отрасль = новая строка |
| `config/ranking.yaml` | веса компонентов значимости, множители ролей, связь факторов с продуктами, ключевые слова поиска позиции банка |
| `config/sources.yaml` | RSS-источники — новый источник = новая строка |

## Компоненты

| Модуль | Назначение |
|---|---|
| `app/ingest.py` | CSV → профили групп; OCR-корпус → FTS5 |
| `app/news.py` | RSS, дедуп и кластеризация, ручной ввод, снапшот |
| `app/llm.py` | доступ к LLM: маскирование, кэш, учёт ₽, лестница бюджета, ретраи |
| `app/classify.py` | классификация новостей |
| `app/rank.py` | объяснимое ранжирование |
| `app/tools.py` | инструменты агента (только чтение) |
| `app/agent.py` | агентный цикл, rule-only карточки, чат |
| `app/schemas.py` | схема Insight v1 и инварианты |
| `app/jobs.py` | фоновые задачи |
| `app/api.py`, `app/metrics.py` | REST + SSE, метрики (Swagger: `/docs`) |
| `web/` | React SPA |
| `scripts/` | OCR (`ocr_analytics.py`), черновик чувствительностей (`gen_sectors.py`), снапшот новостей, золотой набор (`eval_golden.py`) |

## Сценарий проверки

1. `docker compose up --build`, откройте `http://localhost:8000`, войдите как `stroy-cfo`.
2. На главной — виджет «Что важно для вашего бизнеса сегодня» с тремя событиями; наведите на score, чтобы увидеть разбивку значимости.
3. «Все инсайты» → лента: фильтры по риску/возможности, теме, периоду; у каждого события — «почему важно вам».
4. Откройте событие: если инсайт ещё не готов, видна живая трасса агента; затем карточка по 6 вопросам с блоками
   Факт / Мнение Альфа-Банка / Вывод AI и раскрываемыми источниками (новость, страница аналитики, признак клиента).
5. «Как получен вывод» — план, вызовы инструментов, проверки, доработки, токены и ₽ по каждому шагу.
6. В чате справа спросите «Как это повлияет на наш лизинг?» или «Покажи по контрагентам».
7. Нажмите действие («Обсудить с менеджером») и оцените инсайт 👍/👎.
8. Переключите клиента в шапке на «Опт-Импорт», затем «АвтоХолдинг» — лента и интерпретации меняются; смените роль — меняются акценты и порядок.
9. В ленте вставьте текст свежей новости или URL → «Проанализировать для моей компании» → карточка по новой новости.
10. «Метрики»: groundedness, доля инсайтов с позицией банка, доработки, расход ₽, кэш, отзывы, итоги золотого набора.
11. Деградация: перезапустите с `DAILY_BUDGET_RUB=0.01` — новые карточки формируются без AI (`rule_only`), приложение не падает.

## Разработка

```bash
python -m uv sync                       # зависимости Python
python -m uv run pytest -q              # тесты (без сети и без LLM)
BACKGROUND=0 python -m uv run uvicorn app.main:app --reload   # API на :8000
cd web && npm ci && npm run dev         # UI на :5173 с прокси /api
python -m uv run python scripts/eval_golden.py               # золотой набор (нужен ключ LLM)
python -m uv run python -m app.agent group_134409_sb <news_id>  # один прогон агента в консоли
```

## Ограничения

- Поиск по аналитике — FTS5 с префиксным стеммингом, без семантических эмбеддингов.
- Позиция в отрасли и доля рынка — оценка внутри выборки банка, не рыночная статистика.
- OCR может искажать цифры; данные с графиков в PDF не распознаны.
- На демо-срезе (`data/demo/`) платежи есть только у трёх демо-групп: у остальных групп в переключателе профиль без контрагентов.
- Чувствительности отраслей (`config/sectors.yaml`) — экспертный черновик, требует ревью аналитиков.
- Цены моделей в `config/models.yaml` — оценка; заменить на прайс организаторов.
